Hex Player Features

Core video playback and IPTV playlist tools, built from the ground up

Multi-Format Playlist Support (M3U & JSON)

Effortlessly read, parse, and catalog remote IPTV channel structures formatted in raw M3U strings or structured JSON payloads.

Automated Background Playlist Sync

Keep live channel lineups perpetually fresh with silent background re-indexing of linked remote stream sources.

Live EPG & TV Guide Parsing

Extract and render detailed TV guide timelines directly from embedded XMLTV/EPG feeds linked within your playlists.

DASH & ClearKey Playback

Native Shaka Player engine integration capable of processing protected MPEG-DASH media streams with custom ClearKey pairs.

Custom Header & Request Control

Pass custom HTTP request headers, authorization tokens, and User-Agent strings at both playlist fetch and video segment levels.

Adaptive HLS Bitrate Streaming

Powered by hls.js for seamless chunk buffering, real-time quality switching, and borderless immersive viewing.

Instant Channel Search

Zero-latency fuzzy search filter designed to scan through thousands of active media items and categories instantly.

Multi-Track Audio Support

Detects and allows immediate hot-swapping between alternative language tracks and multi-channel audio feeds.

Power-User Keybindings

Comprehensive keyboard bindings to instantly toggle full-screen mode, step through channels, adjust volume, and inspect stream stats.

Modern Dark Interface

Crafted with modern Material design concepts, optimized for eye comfort with true dark/light contrast modes.

Direct Stream Launcher

Quick-launch input bar for testing isolated stream links accompanied by custom authorization and decryption keys.

Native Electron Desktop App

Built upon Electron framework to deliver native OS window controls, GPU acceleration, and efficient memory management.
